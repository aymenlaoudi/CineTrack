# 🎬 CinéTrack

CinéTrack est une application web qui permet de découvrir des films et des séries à partir d'une API MockAPI.

## ✨ Fonctionnalités

- Afficher les films et les séries.
- Rechercher un titre.
- Filtrer par type (Films / Séries).
- Naviguer avec la pagination.
- Afficher les détails dans une modal.
- Ajouter et supprimer des favoris.
- Sauvegarder les favoris avec LocalStorage.

## 🛠️ Technologies utilisées

- HTML
- Tailwind CSS
- JavaScript
- Fetch API
- MockAPI
- LocalStorage
